# Assets

Drop these files in and the page picks them up automatically (placeholders show until then):

- `vsl.mp4` – hero video (autoplays muted; "Click to listen" restarts it with sound)
- `vsl-poster.jpg` – still frame shown before the video loads
- `coach.jpg` – square headshot for the coach section
- `results/*.jpg` – carousel screenshots; filenames are listed in `RESULTS` in `script.js`
